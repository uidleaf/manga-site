# 轻量漫画库 V1

面向“几万本漫画 + 多个来源目录 + 混合 JPG/PNG/WebP”设计的低配置版本。

## 特点
- SQLite：无需独立数据库服务
- FastAPI + 原生 HTML/CSS：依赖少
- 多个漫画根路径，可在后台添加/修改/启用/删除
- 首次全量扫描，之后 Watchdog 实时监控新增/修改/删除
- 新漫画自动建立索引并生成封面缩略图
- 前台分页、搜索、来源筛选、详情、纵向阅读
- 后台管理员 Argon2id 密码哈希 + HttpOnly 会话 Cookie + 登录失败限速
- 删除后台路径只删除索引，不删除硬盘漫画文件

## 目录约定
每个来源路径下，直接子目录视为一本漫画：

```text
漫画根目录/
├── 网站A/
│   ├── 漫画1/
│   │   ├── 001.webp
│   │   ├── 002.jpg
│   │   └── 003.png
│   └── 漫画2/
└── 网站B/
    └── 漫画3/
```

## Windows
双击 `start_windows.bat`。第一次运行会安装依赖并启动。

浏览器访问：`http://服务器IP:8080/`

第一次打开 `/admin` 时可创建管理员。

## Linux
运行：

```bash
./start_linux.sh
```

然后访问 `http://服务器IP:8080/`。

## 低配置建议
- 2 核 CPU / 2GB 内存可用于个人或小规模访问
- 首页每次只取 40 本漫画
- 封面使用小型 WebP 缩略图
- 阅读器使用浏览器原生 lazy loading
- 扫描按“来源”或“单本漫画”增量处理，不会每次全库重扫
- 不依赖 Redis/PostgreSQL/Elasticsearch/Docker

## 生产部署
可以在前面增加 Nginx/HTTPS。当前 V1 为了保持简单，图片由 FastAPI 直接以流式文件响应并设置缓存头；后续访问量增加时，再切换到 Nginx/静态文件方式即可。

## 注意
1. `data/manga.db` 是索引数据库，建议定期备份。
2. `data/config.json` 包含会话签名密钥，也要备份且不要公开。
3. 后台路径输入建议只指向专门的漫画目录，不要指向系统目录。
4. 当前约定为“来源目录 -> 漫画目录 -> 图片文件”。如果你的图片还有更深层级，需要调整扫描器的目录规则。
